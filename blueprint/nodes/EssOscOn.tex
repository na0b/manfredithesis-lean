\begin{definition}
For a measurable set $s\subseteq\R^n$ of positive measure and a function
$f\colon\R^n\to\R$ we set
\[
\operatorname*{osc}(f,s)\;=\;\esssup_{s} f\;-\;\essinf_{s} f .
\]
Following the convention fixed on p.~6 of the paper (``max'' always means
``essential max''), every supremum and infimum of a measurable function over a
set in this development is an essential one.  The quantity is meaningful only
when $f$ is essentially bounded above and below on $s$; every node that uses
$\operatorname*{osc}(f,s)$ carries that essential boundedness as an explicit
hypothesis.
\end{definition}
